# B2B Lead Intelligence & Sales Pipeline System

## 📌 Project Overview

A synthetic B2B sales analytics project designed to demonstrate how lead data can be transformed into actionable business insights using **Excel and Power BI**.

The project simulates a CRM-style sales workflow for a fictional B2B digital solutions company, **GrowthFlow Solutions**.

The company provides:

* Website Development
* CRM Implementation
* Business Automation
* Data Dashboards
* Digital Marketing

## 🎯 Business Objective

The objective is to help a sales team:

* Identify high-potential leads
* Prioritize leads using a scoring model
* Monitor the sales pipeline
* Analyze lead sources
* Understand industry-level pipeline value
* Track lead engagement
* Support data-driven sales decisions

## 🛠️ Tools Used

* Microsoft Excel
* Power BI
* GitHub

## 📊 Project Workflow

**Lead Data → Lead Scoring → CRM Pipeline → Sales Analytics → Power BI Dashboard → Business Insights**

### 1. Lead Database

Created a 100-record synthetic B2B lead dataset containing:

* Company information
* Industry
* Country and city
* Company size
* Contact information
* Lead source
* Estimated deal value
* Contact status
* Follow-up dates
* Sales stage
* Deal status

### 2. Lead Scoring

Developed a scoring model based on:

* Industry fit
* Company size
* Target country
* Estimated deal value
* Engagement level

Leads are categorized as:

* **Hot**
* **Warm**
* **Cold**

### 3. Sales Pipeline

Built a CRM-style pipeline to track leads through:

**New Lead → Contacted → Qualified → Meeting → Proposal → Negotiation → Won/Lost**

### 4. Sales Analytics

Created Excel-based KPIs including:

* Total Leads
* Total Pipeline Value
* Hot Leads
* Warm Leads
* Meetings
* Qualified Leads
* Won Deals
* Lost Deals
* Conversion Rate
* Qualification Rate
* Meeting Rate
* Average Deal Value
* Open Pipeline Value

### 5. Power BI Dashboard

Created an interactive dashboard containing:

* KPI cards
* Lead Distribution by Category
* Leads by Source
* Sales Pipeline by Stage
* Pipeline Value by Industry
* Lead Engagement Status

## 💡 Business Insights

The dashboard can be used to:

* Prioritize high-scoring leads for sales outreach
* Identify stronger lead acquisition channels
* Monitor funnel progression
* Identify potential pipeline bottlenecks
* Compare pipeline value across industries
* Improve follow-up prioritization based on engagement
